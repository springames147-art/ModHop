<p align="center"><b>Free Minecraft mod manager and mod updater for every launcher</b></p>

ModHop moves your Minecraft mods, resource packs and settings to a new Minecraft version or to another launcher. It finds the right build of every mod on Modrinth for the version you pick, adds the mods they need, and leaves out mods that would crash the game.

## Features

- **Update to a new Minecraft version.** Pick a profile and a newer version; ModHop downloads the build of each mod made for it.
- **Switch launchers.** Move a profile between Dawn, Modrinth App, Prism Launcher, MultiMC, PolyMC, CurseForge, ATLauncher and the Minecraft Launcher.
- **Adds missing mods.** Required dependencies are added; mods that can't work are held back and explained.
- **Resource packs and settings.** Game options, mod configs, the server list and resource packs come along.
- **Send profiles to friends.** Send a whole profile, or just resource packs, by Minecraft name. Your friend picks the launcher it goes into.
- **Safe by default.** Files come only from Modrinth and are checked by hash, replaced files are backed up, and ModHop's own updates are signed.

Works with every Minecraft version and with Fabric, Forge, NeoForge and Quilt. Available in English, Hebrew, Chinese, Hindi, Spanish, Arabic and French.

## Install

1. Download [Install-ModHop.cmd](https://da.gd/ModHop).
2. Open it. If your browser or Windows warns about the file, choose **Keep** or **More info → Run anyway** (ModHop is new and not signed with a paid certificate yet).
3. Click **Install**. ModHop adds a desktop icon, starts with Windows and updates itself.

To remove it: Start menu → **Uninstall ModHop**. Your mods and profiles are not touched.
